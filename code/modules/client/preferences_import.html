Bastion Station 13 - Modules - Types

code/modules/client/preferences_import.dm

/proc/preferences_import_readReads a json file into a list, null if it isn't one
/proc/parse_preferences_importReads an uploaded preferences file. Returns list("tree" = the entries that are safe to import) or list("error" = why it was refused)
/proc/preferences_import_character_okA character needs a version the game can load, or loading it throws it away and makes a new one
/proc/preferences_import_text_entriesOnly the text in a list, a number in it would be an index when the game looks it up
/proc/preferences_import_clean_volumesThe sliders save a number from 0 to 100 for each sound channel
/proc/preferences_import_clean_key_bindingsKey bindings are the name of an action with the list of keys it is on
/proc/preferences_import_clean_job_preferencesJob preferences are the name of a job with low, medium or high
/proc/preferences_import_fix_slotsThe default and enabled characters have to be ones that were imported
/proc/sanitize_imported_characterRemoves what the player couldn't pick themselves from an imported character, the loadout and job titles are only checked when they are picked
/proc/apply_pending_preferences_importApplies the import this player staged, called before their preferences load. Returns what to tell them, null if nothing was waiting. The old preferences are copied to preferences.json.importbak first and put back if the new ones can't be saved.
